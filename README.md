# 초등 학생맞춤통합지원 도구 모음 · 논산·계룡

초등학교 담임·상담·교육복지 담당자가 바로 쓸 수 있는 웹 도구 6종입니다.
「학생맞춤통합지원법」(2024. 1. 제정, **2026. 3. 1. 시행**)의 원스톱 절차 — 발굴 → 진단 → 지원 → 성장관리 — 를 초등 현장에 맞춰 옮겼습니다.

충남 **논산시·계룡시** 지역자원 **160곳**이 실제 좌표·연락처와 함께 들어 있습니다.
(지원기관 141곳 + 읍·면·동 행정복지센터 19곳 — 행정복지센터는 성격이 달라 기본 숨김이며 필요할 때만 켭니다.)

## 도구

| 단계 | 파일 | 설명 |
|---|---|---|
| 발굴·진단 | `checklist.html` | 6영역 31문항 진단 체크리스트. 위험도 자동 산출, 우선 지원영역 TOP3, 지역별 1차 연계처 표시 |
| 지원(연계) | `map.html` | 지역자원 160곳 연계 지도. 학교 위치 기준 반경·거리순 정렬, 길찾기 연결 |
| 지원(연계) | `resources.html` | 같은 160곳의 카드 목록판. 적합도 점수순 정렬, 읍면동 근접 가산 |
| 지원(의뢰) | `referral.html` | 교육지원청 공식 의뢰서·동의서 작성. 체크리스트 결과 자동 연동, 신청 사유 초안 생성 |
| 성장관리 | `dashboard.html` | 학생별 지원 이력 타임라인. 중단 건 부각, JSON 저장/불러오기 |
| 안내·소통 | `guide.html` | 제도 안내 원페이지. 교사용 / 학부모용 토글 |

`index.html`이 위 여섯 개를 묶는 시작 페이지입니다.

## 특징

- **설치 불필요** — 각 파일이 독립된 단일 HTML. 더블클릭하면 열립니다.
- **데이터 비저장** — `localStorage`·쿠키·서버 전송 없음. 입력값은 브라우저 메모리에만 있다가 새로고침하면 사라집니다. 이어서 쓸 때는 대시보드의 JSON 내보내기를 쓰세요.
- **자체검증 내장** — 각 파일 하단에 계산 로직 테스트 결과가 표시됩니다 (체크리스트 10 / 대시보드 15 / 카드 28 / 안내 14 / 지도 34 / 의뢰서 24).
- **도구 간 연결** — 체크리스트의 「결과 복사」를 의뢰서 작성기에 붙여넣으면 어려움·요청사항이 자동 체크됩니다.
- **오프라인 동작** — `map.html`만 인터넷이 필요합니다(Leaflet + 지도 타일). 나머지 4개는 외부 의존성이 없습니다.

## 지도 배경 바꾸기 (선택)

기본은 **OpenStreetMap**이라 인증키 없이 바로 뜹니다. 다만 한글 지명이 빈약합니다.
**브이월드(국토교통부)** 무료 인증키를 넣으면 한글 지명 지도와 위성사진으로 전환됩니다.

1. [vworld.kr](https://www.vworld.kr) 회원가입
2. 오픈API → 인증키 → 인증키 발급
3. 활용 API `2D 지도` / 서비스 환경 `웹서비스 URL`
4. URL에 배포 주소 입력 (예: `cosan75.github.io`). 로컬에서도 열려면 `localhost`도 추가 등록
5. `map.html` 상단 `const VWORLD_KEY = '';` 의 따옴표 안에 붙여넣기

넣고 나면 지도 좌측 하단 버튼으로 **일반 / 담백 / 위성 / 위성+지명 / OSM**을 오갈 수 있습니다.

> 인증키는 클라이언트 코드에 노출되는 값이라 **도메인 제한이 유일한 보호 장치**입니다.
> 브이월드 인증키 관리에서 등록 URL이 배포 도메인으로 정확히 지정돼 있는지 확인하세요.
키가 틀렸거나 도메인이 등록되지 않으면 자동으로 OSM으로 되돌아가고 안내 문구가 뜹니다.

> 네이버 지도 API는 무료 이용량이 없고(전량 유료), 카카오맵도 2026-07-21부터 계정당 1개 앱만 무료 쿼터라
> 학교·개인 배포용으로는 브이월드나 OSM을 권합니다.

## 다른 지역에서 쓰려면

지역자원 데이터는 각 파일 안 `const RAW` 블록에 파이프(`|`) 구분 텍스트로 들어 있습니다.

```
시|기관분류|기관명|주소|전화|지원유형(쉼표구분)|공/민|초등적합(1/0)|위도|경도|비고|읍면동
```

[학생맞춤통합지원 누리집 → 내 주변 서비스 찾기](https://studentsupport.kr/center/localList.do)에서
해당 시·군의 목록을 받아 같은 형식으로 바꿔 넣으면 됩니다.
`checklist.html`의 `DOMAINS[].local`, `dashboard.html`의 `ORGS` 배열도 함께 교체하세요.

## 주의

- **참고용 보조 도구**이며 공식 진단·판정 도구가 아닙니다. 지원 결정은 학교 학생맞춤통합지원팀 협의를 따릅니다.
- 아동학대·자해 징후 의심 시 결과와 무관하게 **즉시 신고·보고**가 우선입니다. (아동학대 112 / 청소년상담 1388 / 긴급복지 129)
- 학생 실명 대신 학년·반·번호 사용을 권합니다. 확정된 내용은 학교 공식 시스템(나이스 등)에 기록하세요.
- **`referral.html`은 성격상 실명·생년월일·주소를 다룹니다.** 저장·전송은 하지 않지만, 작성 후 바로 인쇄하고 탭을 닫으세요. 출력물은 학교 규정대로 보관·파기해야 합니다.
- '초등 직접지원' 분류는 기관 성격에 따른 **참고 구분**이며 공식 분류가 아닙니다.
